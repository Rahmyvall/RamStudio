# RAMStudio

Laravel backend for the RAMStudio website: an Admin Dashboard (Gentelella
Bootstrap template in `public/backend-dev`), full CRUD for all 16 data modules,
and a versioned REST API at `/api/v1` with Sanctum authentication.

## Documentation

- **[docs/README_BACKEND.md](docs/README_BACKEND.md)** — installation, admin modules, architecture, testing.
- **[docs/API_DOCUMENTATION.md](docs/API_DOCUMENTATION.md)** — REST API reference with parameters and responses.
- **[docs/RAMStudio.postman_collection.json](docs/RAMStudio.postman_collection.json)** — importable Postman collection.

## Quick start

```bash
composer install
cp .env.example .env
php artisan key:generate      # configure DB_DATABASE=ramstudio_db first
php artisan migrate
php artisan storage:link
php artisan db:seed
php artisan serve
```

Admin dashboard: <http://localhost:8000/admin> (seeded login `admin@ramstudio.test` / `password`).
